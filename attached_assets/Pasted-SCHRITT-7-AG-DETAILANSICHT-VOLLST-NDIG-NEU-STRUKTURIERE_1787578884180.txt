SCHRITT 7 – AG-DETAILANSICHT VOLLSTÄNDIG NEU STRUKTURIEREN UND ALTE ANSICHT ENTFERNEN

ZIEL

Die AG-Detailansicht einer Leistungsanfrage soll vollständig vereinfacht werden.

Es darf nach Abschluss nur noch EINE kanonische AG-Detailansicht geben.

Alle bisher legitim sichtbaren Informationen müssen weiterhin abrufbar bleiben, aber nicht mehr gleichzeitig im Hauptfluss erscheinen.

Die neue Seite soll exakt diese Informationshierarchie besitzen:

1. Header
2. Aktuelle Aufgabe
3. Abstimmung
4. Leistungsanfrage
5. Koordination
6. Verlauf
7. Weitere fachliche Details
8. Technische Details & Übertragung

Prüfe insbesondere:

- leistungsanfragen-detail.tsx
- takt-request-detail.tsx
- App.tsx / Routing
- CoordinationSummary
- CurrentActionCard
- DeadlineCard
- SnapshotPreview
- NotificationPreview
- ResponsePanel
- GUDecisionPanel
- ProposalActions
- ServiceCoordinationTools
- CoordinationHistory
- bestehende Timeline


1. leistungsanfragen-detail.tsx ALS KANONISCHE SEITE VERWENDEN

Die vorhandene produktive:

leistungsanfragen-detail.tsx

refaktorieren.

Keine neue parallele komplette Detailseite erstellen.


2. ALTE takt-request-detail.tsx ENTFERNEN

Wenn nach globaler Suche kein produktiver Import mehr besteht:

Datei löschen.

Nicht als Backup im Source Tree behalten.

Git ist das Backup.


3. LEGACY ROUTE

Alte URL darf nur:

Redirect
→ kanonische Leistungsanfragen-Detailroute

ausführen.

Keine alte UI rendern.


4. ALLE AG-EINSTIEGSPUNKTE PRÜFEN

Mindestens:

- Leistungsanfragenliste
- Coordination Board
- Meine Aufgaben
- Projektseite
- Dashboard
- Benachrichtigungen, falls vorhanden

Alle müssen auf dieselbe kanonische Route führen.


5. ALTE HAUPTSTRUKTUR ENTFERNEN

Auf der neuen AG-Seite nicht mehr parallel als Hauptblöcke rendern:

- CoordinationSummary
- DeadlineCard
- separate Process Timeline
- SnapshotPreview
- NotificationPreview
- ResponsePanel
- GUDecisionPanel
- ProposalActions
- großer ServiceCoordinationTools-Block
- CoordinationHistory

Bestehende Dateien dürfen erhalten bleiben, wenn andere Seiten sie benötigen.

Aber nicht mehr als alte AG-Hauptansicht.
