SCHRITT 10 – VOLLSTÄNDIGEN PNPM CLEAN BUILD, TESTLAUF UND FINALE ABNAHME DURCHFÜHREN

ZIEL

Keine Aufgabe als abgeschlossen melden, solange nicht der vollständige Workspace installiert, typgeprüft, getestet und gebaut wurde.

Es reicht ausdrücklich NICHT:

- nur TypeScript Syntax prüfen
- nur AG-App bauen
- nur einzelne Tests ausführen
- nur API-Server typechecken

Der komplette Workspace muss geprüft werden.


1. REPOSITORY ROOT PRÜFEN

Ausführen:

pwd
ls

Sicherstellen, dass im aktuellen Verzeichnis mindestens vorhanden sind:

package.json
pnpm-workspace.yaml
pnpm-lock.yaml


2. NODE VERSION

Ausführen:

node --version


3. PNPM VERSION

Ausführen:

pnpm --version


4. packageManager PRÜFEN

Root package.json prüfen.

Falls beispielsweise:

"packageManager": "pnpm@9.x.x"

definiert ist:

genau diese Version verwenden.


5. FROZEN INSTALL

Ausführen:

pnpm install --frozen-lockfile

Dieser Befehl muss PASS sein.


6. FROZEN-LOCKFILE-FEHLER NICHT KASCHIEREN

Bei Fehler nicht einfach ungeprüft:

pnpm install

ausführen.

Zuerst Ursache feststellen.


7. LEGITIME DEPENDENCY-ÄNDERUNG

Nur wenn dieser Auftrag tatsächlich:

package.json

verändert hat:

Lockfile bewusst aktualisieren.

Danach erneut:

pnpm install --frozen-lockfile

bis PASS.


8. OPENAPI CODEGEN VOR TYPECHECK

Falls OpenAPI verändert wurde:

bestehenden Codegen-Befehl aus Repository-Scripts ermitteln.

Codegen ausführen.

Keine generierten Dateien manuell patchen.


9. FULL WORKSPACE TYPECHECK

Ausführen:

pnpm -r --if-present run typecheck

Muss PASS sein.


10. API-SERVER EXPLIZIT

Zusätzlich:

pnpm --filter @workspace/api-server typecheck

Falls Workspace-Name abweicht:
→ tatsächlichen Namen verwenden.


11. AG-APP EXPLIZIT

pnpm --filter @workspace/ag-app typecheck


12. AN-APP EXPLIZIT

pnpm --filter @workspace/an-app typecheck


13. LINT

Falls Scripts vorhanden:

pnpm -r --if-present run lint

Keine neue Lint-Konfiguration erstellen.


14. FULL TEST SUITE

Ausführen:

pnpm -r --if-present run test

Nicht nur neue Tests.


15. TESTERGEBNISSE ERFASSEN

Am Ende Anzahl nennen:

passed
failed
skipped

Relevante Skips begründen.


16. KEINE NEUEN SKIPS

Vor Abschluss global prüfen:

.skip
xit
describe.skip

Keine neu hinzugefügten Skips zur Fehlerumgehung.


17. FULL WORKSPACE BUILD

Ausführen:

pnpm -r --if-present run build

Muss PASS sein.


18. AG BUILD EXPLIZIT

pnpm --filter @workspace/ag-app build


19. AN BUILD EXPLIZIT

pnpm --filter @workspace/an-app build


20. API BUILD

Falls Build-Script vorhanden:

pnpm --filter @workspace/api-server build


21. FALLS CODEGEN NACHGEBESSERT WURDE

Nach jeder weiteren OpenAPI-/Codegen-Änderung erneut:

typecheck
tests
build


22. FINALER CLEAN-DURCHLAUF

Der LETZTE technische Lauf soll in dieser Reihenfolge erfolgen:

pnpm install --frozen-lockfile

pnpm -r --if-present run typecheck

pnpm -r --if-present run lint

pnpm -r --if-present run test

pnpm -r --if-present run build

Lint nur auslassen, wenn kein Lint-Script existiert.


23. GIT STATUS

git status --short
